NSU Activity: стартовые компоненты и данные.
1. Из папки проекта установите npm install lucide-react
2. Распакуйте архив в корень ~/projects/nsu-activity (файлы src/App.tsx и src/index.css будут заменены).
3. Запустите npm run dev.
Важно: данные отражают ответы объединений, а не подтвержденное актуальное расписание.
