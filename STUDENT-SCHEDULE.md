# Места активности и персональное расписание

Изменения продолжают существующий React + TypeScript + Leaflet проект. Маршрутизатор, авторизация, сервер и база данных не добавлены; приложение остаётся совместимым с GitHub Pages.

## Главная страница и выбор

Основная навигация: «Карта кампуса», «Каталог объединений», «Моё расписание». По умолчанию открывается карта. Каталог сохраняет поиск, категории, фильтр неактивных объединений, описания и источники. Кнопка карточки клуба добавляет его в личный выбор и открывает расписание.

В расписании доступны все 33 объединения, поиск, флажки и сброс. Сохраняются только ID выбранных клубов в `localStorage` под ключом `nsu-activity:selected-clubs:v1`. Повреждённые значения и устаревшие ID отбрасываются. Если браузер запрещает хранилище, выбор продолжает работать в памяти; интерфейс объясняет, почему он не сохранится.

Семь дней выбранной календарной недели можно просматривать колонками или списком. Карточки отсортированы по началу; разные клубы имеют стабильные цвета и подписи. Карточки расположены последовательным потоком, а не абсолютными прямоугольниками длительности: пересекающиеся интервалы не перекрывают друг друга. Для неизвестного окончания показано только начало; неизвестное начало — отдельный блок «Время уточняется» своего дня.

## Одна модель занятий

`activityModel.ts` объединяет **25 исходных записей** `activitySessions.ts` и **20 точных переносов из описаний каталога**. Её используют и карта, и расписание. ID исходных записей сохранены. В визуальном этапе добавлены изображения в `clubs.json` и по уточнению пользователя обновлены две тренировки СГТ с сохранением предыдущих источников. Помещения, географические вершины, PNG и все 480 контуров не изменены. Подробности: [PHOTO-CATALOG.md](PHOTO-CATALOG.md).

Переносы включают недостающие занятия Swing Dance, Медиваля, Мастерской огня и света, «Миллиона голосов», киностудии, квARTиры, Таверны, Медиацентра и периодичность Дигмы. Переносятся только однозначные дни/время из сохранённого текста. Проекция проверяет точное совпадение исходного расписания **и места**; при изменении текста соответствующая проекция отключится до проверки. Каждая запись сохраняет `catalogSource` с ID клуба и полным исходным текстом. Уже существующее точное занятие не дублируется.

Несколько адресов без соответствия дням не распределяются по занятиям предположительно. База киностудии не становится автоматически местом её вторничной встречи. Понедельничный зал квARTиры остаётся описанием на уровне общежития, без создания новой аудитории или плана. Внешний адрес «Юности» и неопределённые места не получают вымышленных координат: при переходе видны общая карта и описание из источника.

Для Asian Club («Субботы по расписанию»), подразделений ЦСИ, противоречивых расписаний DaNSU и записей без часов/дней нет автоматически придуманных еженедельных встреч. Сохраняется исходное описание в отдельном блоке без календарных записей. Неактивные и нерегулярные объединения также доступны для выбора и показаны отдельно.

## Периодичность и точность дат

Общие функции `sessionSchedule.ts` используются для календаря, ближайших начал и зелёной окраски. `campusTime.ts` задаёт `Asia/Novosibirsk`; время браузера и часовой пояс ОС не определяют дни занятий.

В `ActivitySession` добавлено необязательное `recurrenceRule`; исходная строка `recurrence` сохранена. Поддерживаются:

- `weekly` — известный день каждой недели;
- `interval` — интервал в неделях и `anchorDate`;
- `weeks` — номера недель в цикле, его длина и `anchorDate`;
- `seasonal` — месяцы сезона и вложенное недельное правило;
- `announced` — встречи по анонсам, только с явно заданными `dates`, если они известны;
- `unknown` — описание без вычислимого правила.

Опорная дата определяет неделю цикла, а не начало действия расписания. За срок действия отвечают включительные `validFrom` / `validUntil`. Номера недель внутри цикла начинаются с 1; чётность ISO-недель не подставляется вместо отсутствующей опоры.

Занятия раз в две/три недели и по нечётным неделям без опоры показаны отдельно, с известной периодичностью, но без конкретной календарной даты. Границы периода «осень–зима 2026» для алтимата остаются неизвестными. Явные сезонные месяцы Siberian English Club учитываются с переходом через Новый год; отсутствие окончания не позволяет считать встречу проходящей сейчас.

Встреча «по анонсам» без даты не попадает в недельную сетку. Если в источнике появится конкретная дата, правило `announced.dates` позволяет показать только её, без еженедельного повторения. Тестовые примеры таких правил не добавлены как реальные мероприятия.

**Прежнее допущение «неизвестное окончание = 1 час» отменено.** Зелёный требует полного интервала и вычислимой даты; начало включено, окончание исключено. Ночные интервалы относятся к дате начала. Все регулярные записи — рабочие данные: статусы подтверждения не создают отдельной окраски.

## Карта и единые места

`activityPlaces` — представление над существующими ID, а не новая геометрия. Общежития № 5/6 объединены со своими пристройками. Залы сохраняют номера и исходные описания; неизвестная принадлежность к пристройке не уточняется предположительно. Спортивные объекты собраны в общий раздел; новый и старый комплексы остаются двумя зданиями с разными адресами и контурами. Тир не образует дублирующую карточку старого здания.

Приоритет цветов: зелёный → синий → фиолетовый → серый. Фиолетовый обозначает известную базу клуба/нерегулярных встреч без регулярного занятия в этом помещении. Неизвестные сведения сохраняются в модели, но не дают оранжевую категорию, пунктир или `?`. Серый — отсутствие сведений, а не мероприятий.

Для выбора и клавиатурного фокуса SVG используется обводка самого контура; браузерный `outline` отключён только на интерактивных географических контурах. Обводка не масштабируется вместе с планом. Пунктир убран и у замыкающей линии черновика редактора; алгоритмы редактора и координаты не менялись.

Переход из занятия открывает точную аудиторию/этаж только при определённом помещении. Привязка лишь к зданию открывает его карточку. Альтернативы сохраняются **одной встречей**, без выбора первой аудитории автоматически; пользователь может открыть нужный вариант явно. Неизвестные/разные здания не сводятся к первому известному. Если дата начала вычислена, фильтр карты устанавливается на это начало; для недатированных записей произвольная дата не подставляется. Личные флажки фильтруют расписание, а общая карта продолжает показывать все известные занятия кампуса.

Источники исходной географии и ограничения границ пристроек: [CAMPUS-MAP.md](CAMPUS-MAP.md).

## Проверка

```sh
npm ci
npm test
npm run lint
npm run build
npx playwright install chromium
npm run test:browser
# Или использовать установленный Chromium:
PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH=/usr/bin/chromium npm run test:browser
```

Браузерный тест запускает production preview и проверяет мышь/клавиатуру, 480 контуров, масштаб 100–300%, отсутствие прямоугольного outline и пунктиров, все четыре цвета, редактор, объединение мест, сохранение/сброс выбора после перезагрузки, повреждённое/заблокированное хранилище, пересечения занятий, переходы к точному помещению/зданию/альтернативам, кнопку каталога и ширины 320/390/768/1440 px. Часовой пояс тестового браузера намеренно отличается от Новосибирска. Скриншоты сохраняются в игнорируемом `work/browser-artifacts/`.

Модульные тесты отдельно проверяют периодичности с/без опоры, сезоны, анонсы с конкретной датой, ночные интервалы, отсутствие вымышленных окончаний и дат, происхождение переносов каталога и неизменность геометрии.

Результат проверки этой версии: `npm test` — **60/60**, `npm run lint`, `npm run build` и `git diff --check` — успешно. Production-preview браузерный сценарий прошёл все 480 контуров и оба режима личного расписания на ширинах 320/390/768/1440 px, включая смену недели, перезагрузку, сброс, повреждённое/запрещённое хранилище и переходы к карте. Исключений JavaScript не обнаружено.
