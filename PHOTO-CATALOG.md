# Изображения объединений — уточнение PR № 10

По уточнению пользователя обложки сообществ ВКонтакте полностью исключены из интерфейса: они не показываются ни в карточках, ни в подробностях, ни в панелях карты. Их адаптивные файлы удалены из public. Сведения о рассмотренных исходниках сохранены в манифесте с пометкой excluded; повторный запуск скрипта не возвращает исключённые изображения.

В карточках используются только официальные эмблемы и логотипы из архива: 19 объединений. Основной блок одинаковой высоты 160 px; эмблема ограничена 180 × 120 px, показана целиком с contain, без увеличения сверх исходных размеров. У остальных 14 объединений — единая типографическая заглушка. Баннер не заменяет отсутствующий логотип.

Только обычная фотография горного похода СГТ сохранена как отдельное поле photo, только в раскрываемых подробностях. Она показана целиком, с сохранением пропорций. Все остальные прежние обложки, включая широкие фото и иллюстрации, исключены консервативно, чтобы не использовать оформление шапок ВК. Фото не служит резервным изображением карточки или панели карты.

Просмотрены все 32 файла архива: один побайтовый дубль jven.jpg = омут.jpg. Соответствия, исключения и причины находятся в tools/club-image-inputs.json; SHA-256 и размеры — в src/data/club-image-manifest.json. Исключённые исходники не включены в веб-ресурсы. Изображения из интернета и искусственные фотографии не добавлялись.

Сохранены lossless WebP, пропорциональное уменьшение без ретуши и цветовых фильтров, ICC при наличии, адаптивные srcset, alt, lazy loading и заглушка при ошибке загрузки. Скрипт подготовки (Pillow нужен только разработчику):

```sh
python tools/prepare-club-images.py '/path/to/сайт фото.zip'
```

Остальные функции PR сохранены: поиск и фильтры, действия «В расписание», «На карте», «Сообщество», единый стиль, мобильная версия. СГТ: понедельник/пятница, 19:00, старый спорткомплекс, неизвестное окончание; четверговая лекция сохранена. История источников доступна. Исходные PNG и геометрия всех 480 помещений не изменены.

Проверки: npm test (60/60), npm run lint, npm run build, git diff --check; браузерные сценарии каталога/расписания/карты и всех 480 контуров, ширины 320/390/768/1440 px. Дополнительно проверяются отсутствие баннеров и иллюстраций во всех карточках/подробностях, 19 полных компактных логотипов, 14 заглушек, единственное фото в подробностях и отсутствие увеличения маленьких эмблем.
