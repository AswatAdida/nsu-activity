# Изображения объединений и визуальная доработка

Использованы только файлы пользовательского архива `сайт фото.zip`. Просмотрены все 32 изображения: 31 уникальное, один побайтовый дубль (`jven.jpg` = `омут.jpg`). Они сопоставлены с 23 существующими объединениями по именам и содержимому. Неоднозначных уникальных изображений в архиве не осталось.

## Размещение и подготовка

Данные объединений содержат отдельные `cover` и `logo`, тип, режим отображения, положение, подложку, размеры, alt и адаптивные варианты. Все основные блоки имеют формат 4:3. Эмблемы, широкие баннеры, групповые и вертикальные фотографии показаны целиком (`contain`), чтобы сохранить надписи, лица и композицию. Фотография СГТ уже имеет пропорции 4:3 и использует `cover` с индивидуальной позицией. Дополнительная эмблема доступна в подробностях карточки. Маленькие эмблемы не увеличиваются сверх исходных размеров.

Файлы преобразованы в lossless WebP с пропорциональным уменьшением, без ретуши, цветовых фильтров и изменения содержания. Исходный ICC-профиль сохраняется, если присутствует. Исходники архива не изменены. Общий размер исходных изображений — 18 573 386 байт, всех адаптивных вариантов — 13 074 816 байт. Сумма минимальных вариантов 23 основных изображений — 1 497 016 байт; браузер выбирает размер через `srcset`, изображения загружаются лениво. Все варианты сразу не загружаются.

Повторяемая подготовка (Pillow нужен только разработчику):

```sh
python tools/prepare-club-images.py '/path/to/сайт фото.zip'
```

Проверенные соответствия находятся в `tools/club-image-inputs.json`; SHA-256 исходников, размеры и варианты — в `src/data/club-image-manifest.json`. При ошибке загрузки показывается заглушка с сохранением действий карточки.

## Каталог, расписание и карта

Карточка содержит направление, название, краткое описание, расписание, место и действия «В расписание», «На карте», «Сообщество». Полные сведения и источники сохранены в раскрываемом блоке. Поиск, категории и фильтр объединений без регулярных встреч сохранены; добавлена сортировка. Навигация, расписание, панели карты, кнопки и отступы приведены к общей палитре и типографике.

У существующего объединения «Секция горного туризма НГУ» добавлено поисковое сокращение «СГТ НГУ». Обновлены те же две записи тренировок: еженедельно в понедельник и пятницу с 19:00, старый спорткомплекс, без вымышленного зала и окончания. Четверговая лекция в новом спорткомплексе сохранена. Прежние сведения доступны в примечаниях и истории источников. Неизвестное окончание не заменяется часом и не даёт достоверной зелёной активности.

Кнопка каталога «На карте» открывает известные места клуба и позволяет выбрать конкретную встречу. Для СГТ показаны оба спорткомплекса; неизвестное помещение не заменяется произвольной аудиторией. Используется существующая единая модель занятий, без новых планов, пространственного анализа, сервера или авторизации.

## Проверка

- `npm test`: 60/60; `npm run lint`, `npm run build`, `git diff --check`: успешно.
- Production browser checks: каталог → поиск СГТ → изображение/описание → личное расписание → выбранная неделя → старый спорткомплекс → каталог; также прямой переход из каталога к местам клуба.
- Проверены 23 основных изображения, пропорции, полные эмблемы, отсутствие увеличения маленькой эмблемы, alt/lazy, 10 заглушек и резервное отображение при ошибке изображения.
- Проверены экраны 320, 390, 768 и 1440 px, отсутствие горизонтального переполнения страницы, фильтры и мобильные действия.
- Существующие браузерные проверки всех 480 контуров, этажей, редактора, фильтра времени и личного расписания проходят. Исключений JavaScript нет. Исходные PNG и геометрия помещений/зданий не изменены.

Ограничения: наличие изображения не подтверждает актуальность расписания; неизвестные время окончания и помещение остаются неизвестными. У 10 объединений нет файлов в архиве. Загрузка картографических тайлов зависит от внешнего OpenStreetMap; сохранён и проверен существующий резервный режим при недоступности тайлов.
