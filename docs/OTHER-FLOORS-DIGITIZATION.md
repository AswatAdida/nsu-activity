Пользовательский экспорт `room-polygons (3).json` содержит 97 контуров,

не входят даже в этот черновик. Здания, расписания, посещаемость,
назначение помещений и связи с клубами по геометрии не угадывались.

## Просмотр

Страница `/nsu-activity/review/other-floors.html` позволяет:

- переключать все этажи, включая сохранённый третий;
- отличать свою/прежнюю разметку, новые предложения и спорные участки;
- увеличивать общий план и включать/выключать наложение;
- выбирать помещение и сравнивать его крупный исходный фрагмент с контуром;
- скачать 377 предложений отдельно либо общий черновик для импорта в редактор.

Страница работает с GitHub Pages BASE_URL и не меняет данные автоматически.
Для переноса предложений в основную карту после проверки потребуется
обновить основной JSON и справочник помещений. Само скачивание или импорт
в браузер не публикует контуры.

## Метод и источники

Зелёные стены выделены тем же порогом, что в редакторе. Замкнутые области
найдены по связанным компонентам; небольшие изолированные рамки легенды
отделены от основного каркаса стен. Номера распознаны Tesseract по отдельным
областям и визуально сверены с контактными листами исходных подписей.
Ошибки OCR исправлены по читаемым цифрам на плане, а не по предположению
о нумерации этажей. В отчёте сохранены исходные результаты OCR.

Изображения PNG не редактировались. Для пяти явно проверенных комнат
(0288, 0298, 2127, 2125, 2124) небольшой видимый дверной разрыв замкнут
только в рабочей маске. Это не автоматическое достраивание всех дверей:
такие случаи помечены отдельно в отчёте и странице проверки.

Каждое предложение содержит исходную точку, площадь в пикселях, число
вершин, путь и SHA-256 оригинального изображения. Площадь в пикселях
не является площадью помещения в квадратных метрах. Сохранены все
пиксельные углы, кроме строго коллинеарных промежуточных точек;
произвольное сглаживание не применялось.

## Исключения

В отдельный список вынесены семь областей:

- этаж 1: две разные области с одной подписью 1280;
- этаж 2: область 2137/2138 с неоднозначной внутренней границей;
- этаж 4: две разные области с одной подписью 4316;
- этаж 4: области, прямо подписанные на оригинале 3307 и 3107.

Номер 1239 найден в легенде первого этажа, но однозначная подписанная
область для него не определена. Ненумерованные комнаты, лестницы,
санитарные помещения и серые технические зоны не получили вымышленных
номеров. Поэтому этот результат нельзя называть полной инвентаризацией
всех пространств здания.

## Файлы и воспроизведение

- `public/data/room-polygons-other-floors-candidates.json`: предложения.
- `public/data/other-floors-review.json`: отчёт, исходные точки, результаты
  OCR, ручные поправки подписей и исключения.
- `tools/reproduce_floor_candidates.py`: повторное построение по уже
  проверенным подписям и точкам. Этот инструмент не выполняет OCR заново.

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -r tools/requirements-batch-floorplans.txt
.venv/bin/python tools/reproduce_floor_candidates.py \
  --output /tmp/other-floors-reproduced.json
cmp public/data/room-polygons-other-floors-candidates.json /tmp/other-floors-reproduced.json
npm test
npm run build
```

Использованы Pillow 13.0.0, NumPy 2.3.5 и SciPy 1.17.0; Tesseract доступен
как отдельная системная команда. Приложению Python, Tesseract и новые
npm-зависимости не требуются. Воспроизведение проверено побайтовым сравнением.
