## Результат

На оригинальном `public/floorplans/floor-5.png` размером 2048 × 2048
выделена замкнутая область аудитории 5222. Выбор аудитории и начальной
точки `(110, 870)` выполнен человеком по подписи на плане. Алгоритм
сам нашёл внутреннюю границу стен; OCR не выполнялся.

Получено восемь вершин, площадь внутренней области — 7656 пикселей.
Независимая точка `(100, 860)` даёт тот же результат. В площадь входят
чёрные подписи: они не считаются стенами. Это не оценка площади в м²
и не показатель точности распознавания.

Небольшая неровность стены справа сохранена. Удалены только строго
коллинеарные точки пиксельной границы. Разрывы стен не достраивались,
изображение не масштабировалось и не изменялось. Контур проходит по
внутреннему краю зелёных пикселей, а не по оси или внешнему краю стены.

JSON-кандидат: `public/data/room-polygons-5222-candidate.json`.
Метод и SHA-256 исходного изображения: `docs/room-5222-detection.json`.
Сравнение: `docs/room-5222-preview.png` и страница просмотра ниже.

## Воспроизведение

Зависимость нужна только Python-инструменту, не React-приложению:

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -r tools/requirements-floorplan.txt
.venv/bin/python tools/detect_room.py \
  --image public/floorplans/floor-5.png \
  --seed 110 870 --room 5222 --floor 5 \
  --output public/data/room-polygons-5222-candidate.json \
  --report docs/room-5222-detection.json
.venv/bin/python -m unittest discover -s tools -p 'test_*.py'
npm test
npm run build
```

В текущей среде использован Pillow 13.0.0. Новые npm-зависимости не нужны.

## Как работает метод

1. Зелёные пиксели стен: `G > 100`, `G > 1.25 × R`, `G > 1.25 × B`.
2. Из заданной точки выполняется заливка по четырём соседним пикселям,
   не переходящая через зелёные стены.
3. По границе найденной области строится направленный замкнутый контур.
4. Строго коллинеарные промежуточные вершины удаляются.
5. Координаты пикселей переводятся в существующую SVG-систему 0–1000
   с округлением до 0,1, как в ручном редакторе.

Инструмент отказывается от областей, доходящих до края изображения,
занимающих больше 5% изображения, имеющих неоднозначную границу или
отверстия. Он также отклоняет точку на стене и точку вне изображения.

## Ограничения и следующий шаг

Это успешная проверка **одного помещения**, а не готовое распознавание
всего корпуса. Число помещения и принадлежность области не определяются
автоматически. Зелёные подписи, открытые двери и стены другого цвета
могут мешать. Если проём соединяет две небольшие комнаты, заливка может
получить обе: ограничение площади не доказывает, что найдена одна комната.

Следующий шаг — проверить метод на нескольких заранее выбранных
помещениях с разной геометрией и дверями. После этого решать, стоит ли
переносить поиск по клику в редактор и добавлять OCR. Массово публиковать
контуры без проверки по этому эксперименту нельзя.
