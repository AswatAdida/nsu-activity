# Room activity

Room contours keep their original coordinates, physical IDs and PNG files. Selection is a thick dark stroke on the actual shape. Keyboard focus uses that same shape, without a rectangular browser outline. No map, floor-plan or editor-preview mode uses dashed contours.

Current colour priority:

1. Green: an exact dated occurrence with a known start **and end** is scheduled now.
2. Blue: regular classes are recorded, including incomplete periodic schedules.
3. Purple: a club base or announced/irregular activity, without a regular class record.
4. Grey: the database has no activity evidence; this is not proof that no activity exists.

Source confirmation fields, unknown times and reasons remain in the data model; they do not create another visual category. No default duration is inferred. Recurrences and the shared map/calendar model are described in [STUDENT-SCHEDULE.md](STUDENT-SCHEDULE.md).
